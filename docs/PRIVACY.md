# Privacy and data handling

## Repository rule

Do not commit PHI, PII, real patient records, private learner records, credentials, API keys, or confidential institutional material.

## Examples and test data

Prefer clearly labeled synthetic data. De-identification is context-dependent and should be reviewed before sharing. Removing names alone is not necessarily sufficient.

## Future application design

Before collecting any user or learner data, document:

- what is collected and why;
- where it is stored and for how long;
- who can access it;
- how users can correct or delete it;
- which third parties receive it;
- applicable institutional, contractual, and legal requirements.

Use data minimization, least-privilege access, encryption in transit and at rest, and an incident-response process appropriate to the deployment context.
