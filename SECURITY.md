# Security policy

## Supported versions

This project is in early development and has no supported production release.

## Reporting a vulnerability or privacy concern

Do not open a public issue for suspected vulnerabilities, exposed secrets, PHI, PII, or other sensitive data. Contact the repository owner privately through their GitHub profile and include only the minimum information needed to coordinate a secure report.

Do not include real patient information in a report. If sensitive data was committed, notify the owner immediately and avoid copying or redistributing it.

## Scope

Relevant reports include:

- exposed credentials or private data;
- authentication or authorization flaws;
- unsafe storage or transmission of learner data;
- prompt-injection or data-exfiltration risks;
- misleading clinical output that could create a safety risk.
