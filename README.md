# Clinical AI Education Tool

An early-stage educational project for teaching responsible, evidence-aware use of artificial intelligence in clinical learning environments.

> [!IMPORTANT]
> This repository currently contains the project and collaboration framework. The application source and validated educational content have not yet been added.

## Project status

**Early development.** Nothing in this repository is a medical device, clinical decision-support system, or substitute for professional judgment. Do not use it to diagnose, treat, or make decisions about an individual patient.

## Intended audience

- Health-professions educators
- Students and trainees
- Clinicians learning about AI
- Researchers and developers working on clinical AI education

## Safety and privacy

- Never add protected health information (PHI), personally identifiable information (PII), real patient records, credentials, API keys, or private institutional data to this repository.
- Use synthetic or properly de-identified examples only.
- Treat AI-generated output as unverified until a qualified human reviews it.
- Educational and clinical claims should cite reliable sources and include a review date.
- Report security or privacy concerns using the process in [SECURITY.md](SECURITY.md), not a public issue.

## Collaborating

The repository is publicly readable. Approved collaborators may create branches and open pull requests. Start with [CONTRIBUTING.md](CONTRIBUTING.md), then review:

- [Project charter](docs/PROJECT_CHARTER.md)
- [Clinical content review](docs/CONTENT_REVIEW.md)
- [Privacy and data handling](docs/PRIVACY.md)

## Responsible sharing

When sharing the project, describe it as an early-stage educational tool. Do not imply clinical validation, regulatory clearance, institutional endorsement, or suitability for patient care unless those claims are documented and approved.
